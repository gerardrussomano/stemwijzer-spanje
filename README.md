# Stemwijzer Spanje

Voting-advice test for Spain's general election of **29 November 2026**, in Spanish, Dutch and English.

- 33 statements on housing, taxes, work, immigration, territory, equality, energy and foreign policy
- 26 national and regional candidacies, filterable by region
- Match percentage per party, with important topics counting double
- Statement-by-statement comparison and a left–right / centralist–plurinational map
- The closest Dutch party for every Spanish party

It is a single static file (`index.html`) with no build step. Answers are stored only in the visitor's browser.

Party positions are an editorial estimate based on manifestos, votes in Congress and public statements. They are not official. Not affiliated with ProDemos or any party.
